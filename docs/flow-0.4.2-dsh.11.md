# 0.4.2-dsh.11：提示刷新、连续操作与收尾回执

日期：2026-11-18。继续使用 BrowserSkill 0.4.2 / 协议 1.8，不修改 Harness 内核或引入新运行依赖。

## 提示刷新

指针原本已异步转发。本轮把步骤提示的开始、结束状态也移出动作等待链：每个标签有序发送，至多保留一条最新待发状态；慢内容脚本不会让后续输入等待界面确认。任务变化或结束后，过期提示失效。黄色渐变、指针、粒子、点击反馈和用户操作锁保留，实际操作仍执行原来的归属、上下文与命中检查。

## 批量内等待

已观察、已决定的 1..8 个动作继续使用 batch。每步可以带 `untilVisible` 与 `waitTimeoutMs`，复用原生 step 等待已知主文档 CSS 目标、同步页面，再执行下一步。等待预算 1..25000ms，整个批次的总时限仍有效。

等待超时可能发生在输入已经完成之后。检查原始 action/readiness/post 回执，重新观察和规划，不能重复已经执行或效果不明的动作。批量开始前验证所有步骤，人工接管、取消或任一步异常都会停止后续步骤。

## 可核实的收尾

模型选择的 `requestedKeepTabIds` 与实际剩余页面分开。两端具备清理回执能力时，`finish` 增加实际 `closedTabIds`、`retainedTabIds`、`failedTabIds`、`unknownTabIds`，以及 `cleanup.entries` 的状态与保留原因、窗口状态。

页面 ID 来自本任务窗口预先核实的标签清单。扩展在原生清理后再次查询这些页面：明确不存在才记为 closed，查询失败记为 unknown，仍存在但应清理的页面记为 failed；明确保留、借入、人工操作或表单/不确定内容分别说明。复用空闲插件窗口时，已有结果或用户页另行标记并继续保留。字段不包含页面地址、内容或输入值。

CLI 的持久化停止协议保持不变。补充回执经本机受限接口传回，绑定实际扩展 ID、任务请求和单次随机凭据，拒绝外来来源、换主、额外页面和伪造结果。旧扩展、接口故障或缺失回执时，`cleanup.confirmed:false` 如实说明没有确认；证据通道失败不会触发输入重放、强制关页或掩盖真正的停止错误。

停止失败且已有可信回执时，原错误附带清理证据，仍以失败返回；不会把剩余页面或未释放控制显示为完成。

## 后台托管

后台脚本遇到短暂 IPC 读错、状态解析失败或异常退出时记录并重试。无法判断现有 daemon 状态时先继续检查，避免启动竞争实例。脚本和子进程保持隐藏，日志留在安装目录。新安装的计划任务支持有限的异常重启；已有安装更新前先检查任务状态，避免中断其他浏览器工作。

## 兼容与验证

diagnose 分别报告修订一致、输入兼容、清理回执和异步提示能力。兼容旧版输入不代表它已加载新特性。功能实现与原生检查已完成；本轮实测数据见[验证记录](validation-0.4.2-dsh.11.json)。

研究 ego-lite 的公开 SDK 设计后，本轮只实施已证实有需求的改进。局部快照、站点经验和通用模型脚本执行不在本版功能范围。性能数据针对独立本机合成页面，须与模型推理、网站网络和完整任务耗时区分。[参考与取舍](reference.md)。

更新和回滚见[安装说明](installation.md#日常更新与使用)。

## 本机延迟对照

独立 headless Edge，同一合成页面，每种条件预热两次、记录十次原生 step；step 包含点击、原生检查及同步，不含模型推理和外网。延迟只注入步骤提示的界面回执。

| 版本 | 模拟提示回执延迟 | P50 | P95 | 样本数 |
| --- | ---: | ---: | ---: | ---: |
| .10 | 0 ms | 235 ms | 261 ms | 10 |
| .10 | 40 ms | 273 ms | 377 ms | 10 |
| .11 | 0 ms | 256 ms | 390 ms | 10 |
| .11 | 40 ms | 239 ms | 249 ms | 10 |

普通场景没有据此建立通用提速结论；慢回执场景单列。带明确等待的两步流程从两次模型工具调用合并为一次；首次批量仍包含一次能力核查，底层命令数不会因此自动减少。

原生 Windows 的隐藏桌面保留输入回执与渲染帧等待，不能把 headless 数值外推给它。标准桌面夹具保留一个独立普通窗口，并检查它未被接管或关闭；全部四组候选检查共 67 项通过，476 次桌面采样没有测试辅助窗口或前台焦点违规。

无普通窗口的另一个冷启动夹具出现窗口状态恢复为普通/聚焦的异常，已单独记录；默认桌面监测未见抢焦点，本版未宣称修复该边界条件。
