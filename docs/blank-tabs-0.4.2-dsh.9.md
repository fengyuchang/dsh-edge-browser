# 0.4.2-dsh.9：空标签归还与会话保护

日期：2026-11-17。CLI / 协议继续使用 0.4.2 / 1.8。

## 行为变化

- 新建或借用的 `about:blank` 没有可读取的内容时，同步返回 `ready:false`、`reason:blank_page` 和恢复提示，不生成页面输入上下文。新任务页导航到目标 URL 后可正常同步。
- 标签管理保留归属、暂停、人工操作、取消和最终调度检查；不可注入的页面不会阻塞整个任务窗口的切换、归还。借用的用户空白标签保持原 URL，可归还到原窗口和原位置。
- 截图的 `not_found` 可能指向已变化的文档或截图目标。后台缩略图先用守护进程的会话清单确认任务确已消失，再清除聊天归属。查询失败、格式不明确或仍存在时保留任务；旧请求也不能清除后来替换的任务。
- 严格观察变化时提示 `bsk_session(action=sync)`；确定属于其他聊天与本聊天没有可用任务分别说明恢复方式。会话隔离和脚本检查继续生效。

空白页的“没有内容”不代表任务已经完成，也不授予点击或脚本执行权限。归还后浏览器任务可继续操作其他标签。建议新任务明确传入目标 URL；不再通过反复刷新空白页恢复。

## 验证

3,740 项扩展测试、724 项原生测试通过，435 项跳过，两端类型检查通过。46 项真实隔离浏览器检查通过；桌面监测 172 次采样无测试进程可见窗口或前台焦点违规。8 次点击截图共采样 407 帧，光晕/控制条隐藏或移除均为 0。

公开、去除部署身份的数据见 [validation JSON](validation-0.4.2-dsh.9.json)。本轮在独立浏览器配置、独立守护端口和合成聊天中测试，没有向真实聊天发消息。

`.8` 基线真实复现了空标签同步失败、借用空标签后无法归还；新建空标签后切回原任务页在本次基线中仍成功，因此不将所有标签切换都记为必然失败。

`.9` 在 headless Edge 与非活动 Windows 桌面的原生 Edge 中验证了新建、借用、原样归还、跨会话隔离、无输入授权、带 URL 新建、后台首截与收尾。原生 Edge 使用 `--no-startup-window`，不传初始窗口尺寸。额外复验人工接手、输入锁、取消、表单保护与点击截图动效。

本轮未自然复现 `.8` 的截图超时；核对到的原始超时回执来自加载 `.8` 以前。截图保留 `.8` 的渲染保活与分阶段诊断，不对仍未返回的 Chrome 命令启动重叠重试，也不自动重放点击、提交或脚本。不声明通用提速倍数或所有网站均无超时。

## 更新

先备份并替换两端文件，等现有任务结束后重新加载 Edge 扩展，并重启实际托管 Harness 的服务。使用启动器时须退出并重开启动器；只关闭工作台可能保留旧后台。核对运行状态和 diagnose 均为 `.9`，已确认新版的一端无需重复加载。参见[安装与更新](installation.md#日常更新与使用)。
