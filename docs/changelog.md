# 更新记录

## 0.4.2-dsh.2 · 2026-11-07

- 修复 DSH 0.2.2-rc.1 中切换模型后，局部标注仍按最初模型的图片能力发送附件的问题。读取 `agent.model.current()`，旧内核或尚无已选模型时回退到 `agent.options`。
- 新增纯文本与图片模型双向切换、无已选模型回退的回归检查；使用当前内核真实 `AgentModel` 和消息工厂验证。
- 在独立、无桌面窗口的 Edge 中验证六个工具、会话隔离、填写、step、预览、取消及任务结束后的页面保留和控制释放。
- 仅更新 Harness 原生插件。扩展和 CLI 仍为 0.4.2、协议 1.8；不用为这次修复重新加载 Edge。未升级其他插件或内核。
- 打包和依赖锁定工具改为读取实际包版本，避免补丁发行时仍写入旧版本号。

## 0.4.2-dsh.1 · 2026-11-06

- 三端升级至 BrowserSkill 0.4.2、协议 1.8，保留 DSH 定制功能。
- 原生 step、可复用目标上下文、expect、拖动、日期输入及合作控制。
- 预览改为受限本地 IPC，取消每帧子进程与临时文件；预览不隐藏浮层，模型截图保持原行为。
- 鼠标可视化退出原生输入关键路径；保留轨迹、点击、暂停/接手清理。
- 停止回执在原生生命周期中按聊天解析，保留取消重试语义。
- 任务和保留页后台打开，默认不请求前台焦点，普通任务立即最小化。
- 固定上游源码补丁、可读定制源文件、输入/产物哈希，支持源码重建；支持固定本地原生包以防定制被市场包覆盖。
- 验证与实测范围见 [升级说明](upgrade-0.4.2.md)。

## v0.3.3-dsh.r8 · 2026-11-06

- 修复点击时指针和控制提示层被反复移除、重新插入，导致动效闪烁的问题。浮层已经处于正确顺序时保持原位；页面出现新浮层时仍可调整显示顺序。
- 新增页面回归检查：8 次点击绕过状态切换中，浮层移除次数由修复前的 32 次降至 0，保留标注、提示收起和输入穿透行为。
- 已在重新加载扩展的真实 Edge 中连续执行 12 次原生点击；浮层移除次数为 0，161 次状态采样中黄色边框和控制条持续可见，边框动效未重置。
- r7 用户更新 Edge 扩展并重新加载后生效；已打开的旧页需刷新或创建新任务页。Harness 原生插件沿用 r7，无需为本次修复重启 Harness。

## v0.3.3-dsh.r7 · 2026-11-04

- 增加跨网站的定位与观察恢复矩阵：查询语法错误、未匹配、不可见、失效引用、失效分页和失效会话分别处理。
- 定位优先使用当前观察的引用，再用已核实 CSS；明确 `text=…` 不受支持，避免拼接猜测选择器或命中隐藏按钮。
- 失败后重新观察并核实是否已生效，再有限重试；页面稳定时允许复用引用，避免每次点击都做全量观察。
- 数据读取连续受阻时可按既有流程用只读 debug 抓包诊断，不自动重放请求、切换控制后端或越过人工登录。

## v0.3.3-dsh.r6 · 2026-11-02

- 主技能增加必须执行的登录接手流程：任务被登录、扫码、短信验证码或人机验证阻挡时，立即调用 `bsk_assist(action=request-help)`，不能只在聊天中提醒或等待网页加载。
- 工具说明和结果提示同步强化同页等待、点击“完成并交还控制权”、重新观察确认成功，以及取消、超时、禁用时的处理。
- Harness 工具卡直接显示接手标题和具体操作说明，方便用户知道当前在等什么。
- 不因页面上存在普通“登录”入口强制接手；不使用已经满足的完成条件误判登录成功，也不自动修改人工协助设置。
- 协助开关状态未知时直接调用接手工具，由扩展执行用户设置；不会因 Harness 未返回“已启用”而漏发求助。

## v0.3.3-dsh.r5 · 2026-11-01

- 新增 `bsk_session(action=finish, keepTabIds)`：模型在最终回答前判断结果页去留，保留待阅读、待人工操作与未保存表单，关闭临时中间页。
- 保留页移动为普通页面，释放调试连接、浮层、指针和临时静音；原有借入标签始终按原路径归还。
- 正常轮次结束、取消或错误停止时兜底收尾；模型遗漏判断则保留所有剩余页面。直接拥有者隔离，父聊天结束不关闭仍在工作的子任务浏览器。
- 页面转移失败保留回执并拒绝继续关闭，支持安全重试。
- README 与项目主页改为展示黄橙渐变光晕、真实网页上的 DeepSeek 指针，以及同版组件的放慢彗尾与粒子演示。
- 新增收尾回归和真实 Edge 检查，覆盖未保存输入保留、无用页关闭和结束后自动释放控制。
