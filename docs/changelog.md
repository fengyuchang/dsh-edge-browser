# 更新记录

## v0.3.3-dsh.r4 · 2026-11-01

- 标注接收目标改为实际创建浏览器任务的原聊天，切换查看其他聊天不再误投。
- 检查原生任务归属、子任务父聊天和附件保存后的归属变化；原聊天空闲仍可接收，归属不明时保留建议。
- 修复工具不可用／恢复通知残留的旧 `source.kind=plugin`，消除该路径的 format v4 来源报错。
- 增加误路由与通知来源回归检查，更新操控页面的说明与演示。

**r2/r3 已被本版替代。** 两版的选中聊天路由和工具通知来源仍有已知问题，建议升级 r4。

## v0.3.3-dsh.r3 · 2026-11-01

- 原生可配置快捷键：Alt+Shift+A 打开局部标注。
- Enter 发送、Shift+Enter 换行、Esc 取消；中文组合输入与长按保护。
- 发送失败保留错误提示、框选和建议。
- 发布完整开源发行代码、构建脚本、安装文档和项目主页。

## annotations r2 · 2026-11-01

- 目标改为 Harness 输入栏同步的选中聊天，展示名称与 ID 尾号。
- 拒绝缺失、含糊或变化的选择，不回退到其他忙碌聊天。
- 使用当前 Harness v4 支持的 producer-owned 消息来源。
- 浏览器工具、默认会话、列举与停止按调用聊天隔离。
- 真实标注进入指定聊天并继续回复已人工确认。

## annotations r1 · 已被修正版替代

- 方框标注、裁剪截图、建议发送与独立收起控件。
- 初版真实使用暴露旧会话误路由和 format v4 来源错误；请使用 r4 及后续版本。
