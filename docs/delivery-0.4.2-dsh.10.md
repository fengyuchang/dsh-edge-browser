# 0.4.2-dsh.10：截图交付、兼容与空闲策略

日期：2026-11-17。CLI / 协议仍为 0.4.2 / 1.8；未更换守护进程二进制或 Harness 内核。

## 截图交付

之前在支持图像的模型路由上，截图保存为附件后会删除临时 PNG，但结果仍带有该路径。现在成功结果保留真实、可读取的文件，`byteSize` 使用实际文件字节数；对话内图片与文件可同时使用。保存附件期间取消则不返回交付结果，并清理该临时 PNG。临时目录不替代用户指定的交付目录，需复制并核验交付文件。

## 修订兼容

之前语义定位和 batch 要求扩展修订号完全一致。现在接受已测试的 `0.4.2-dsh.8` 至 `0.4.2-dsh.10` 范围；更旧、未知或未经验证的未来版仍拒绝这些高级输入。页面权限、观察上下文、人工接手和聊天归属检查不变。

diagnose 中 `runtimeMatchesPlugin` 仍表示精确一致，新增 `compatibleForInput` 与 `updateRecommended`。兼容并不代表旧扩展拥有后来加入的空标签等修复，仍建议更新两端。基本 ref/CSS 操作此前不经过该高级能力门，本轮不将旧问题描述为所有点击全部失效。

## 收尾的实际含义

真实对照确认普通无表单任务页在 `finish(keepTabIds:[])` 后会关闭。借用页、人工碰过的页、未提交表单和内容不确定的页仍按原生保护保留。新增 `requestedKeepTabIds`、`protectedPagesMayRemain` 和说明，明确显式保留列表不包含所有原生保护结果；`controlReleased:true` 表示已释放控制，不能单独作为全部标签已关闭的证据。

## 空闲会话

后台缩略图请求会更新守护进程的会话活动时间，可能让不用的探针持续存活。现在模型工具五分钟无活动后暂停自动取图，改为仅查询会话存在性。这不会主动停止会话；守护进程继续按自己的空闲、忙碌和人工操作策略回收。默认情况下，暂停后可能再需要一个五分钟空闲周期及扫描间隔，不能理解为五分钟一到就强制退出。

新工具活动会恢复预览。列出会话或本地容量已满时，只清除守护进程确认已经消失的活动记录，释放被幽灵记录占用的槽位；查询失败、清单格式不明及正在使用的任务均保留，不接管其他聊天。

## 验证边界

3,740 项扩展测试、738 项原生测试通过，435 项跳过，两端类型检查通过。44 项真实隔离浏览器检查通过，包含接收端 .10 与扩展 .8、.9、.10 的配对，以及原生 Windows Edge。205 次桌面采样未观察到测试窗口出现在用户桌面或取得前台焦点。

见[公开验证数据](validation-0.4.2-dsh.10.json)。浏览器和守护进程均使用独立配置；截图来自合成页面，附件服务使用本地结构化测试接口承接真实 PNG 字节。人工插入测试只在私有 headless / 非活动 Windows 桌面的浏览器中前置窗口。

空闲验证将预览服务时钟推进五分钟，并把真实测试守护进程的空闲周期设为两秒，以有界验证“暂停预览后可回收”。本轮没有等待日常默认十分钟窗口的完整时长，也没有以单次调用作为通用速度倍率。原有截图超时和阶段诊断保持，未增加不确定输入重放。

更新方式见[安装与更新](installation.md#日常更新与使用)。使用启动器时须重启实际托管 Harness 的服务；已确认新版的一端无需重复加载。
