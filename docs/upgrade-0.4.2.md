# 0.4.2 大版本与验证

本版统一扩展、CLI、原生插件到上游 0.4.2 / 协议 1.8。保留黄色渐变、彗尾指针、标注、人工接手、静音、分组和任务结束收尾。仅升级浏览器组件，不升级 Harness 核心或其他插件。

| 同一隔离页面，真实命令 | 中位耗时 | P95 | 样本 |
| --- | ---: | ---: | ---: |
| 点击后单独 sync | 418 ms | 497 ms | 30 |
| step：一次点击并 sync | 324 ms | 338 ms | 30 |
| 新预览 IPC | 57 ms | 76 ms | 10 |
| 同版本 CLI 正式截图 | 159 ms | 166 ms | 3 |

step 比本次两次调用少约 22% 的本地耗时；预览比较只是本机路径测量。不能推算所有网站或整个 AI 任务都会同比加速。测试排除模型、审批和外网，页面无业务负载；每组先预热，初始基准的日常 Edge 与本次无桌面测试实例也不宜作严格横向对比。

实际执行 66 次点击，检查副作用总数。连续 13 次人类预览期间浮层未隐藏；3 次模型截图仍触发干净捕获。两聊天独立任务、外部任务拒绝、保留未提交表单、撤下指针、只结束自身任务通过。Edge 源码测试覆盖取消、交还、目标失效、原生日期与拖动等路径。界面标注接收、原聊天路由与 v4 来源另有可重复合成检查。

默认任务窗口不请求前台焦点；Windows Edge 对创建时 minimized 的行为不可靠，所以拿到窗口 ID 后立即再最小化。此轮后续浏览器验证全部用独立 headless 配置，不加载用户网站登录信息；它不能证明所有桌面环境绝无窗口闪现。用户主动查看和人工接手允许显示任务页。

已暂缓：全工具迁移到常驻 MCP、升级 Harness 核心/桌面 beta、自动安装或修改其他插件。这些不作为本版稳定性前提。
