# Patched BrowserSkill native plugin

This directory contains the complete BrowserSkill 0.3.3 native Harness plugin distribution with this project's annotation receiver, selected-chat client bridge, browser ownership guard, and synchronized skill. Read the [project installation guide](../../docs/installation.md).

The package name is retained for Harness compatibility. Publishing this vendor identity to npm is disabled. Upstream development-only scripts and workspace dependencies are omitted because their TypeScript build inputs are not part of the published distribution.

Original source, build tooling and upstream documentation: [Tencent/BrowserSkill](https://github.com/Tencent/BrowserSkill/tree/main/packages/dsh-plugin-browserskill). MIT copyright Tencent; annotation client adaptation attribution is in LICENSE.dsh-doyourweb.txt.
